# Vouchere

Listă dublu înlănțuită cu vouchere citite din fișier.

## Funcționalități

- citirea voucherelor din `vouchere.txt`
- afișarea în ambele sensuri
- valoarea totală a voucherelor unui beneficiar
- ștergerea voucherelor expirate față de data curentă
- dezalocarea memoriei

## Structura de date

`Voucher`: număr, beneficiar, data expirării, valoare.

## Rulare

Se deschide `voucher.sln` în Visual Studio. Fișierul `vouchere.txt` trebuie să fie în directorul de lucru.
